# Session 2026-06-10 — CLI-first pivot + endoflife + discoverability

Soft status / report for the work after the daemon-first v1 (`v0.1.0`). Not a
spec; a running log of what shipped, what's verified, and what's still open.

## Shipped

- **CLI-first architecture** (`v0.2.0`). Local CLI talks straight to SQLite +
  feeds by default (`LocalBackend`); daemon is a secondary transport
  (`RemoteBackend`, via `--remote`/`HOMEWATCH_URL`). Single-shot `refresh` is
  the cron-friendly default; `watch` is the bounded "watchman" loop
  (`--until-new`, `--for`). On-demand full notes via `show` (DB stores a ~280c
  summary + link).
- **Per-user data root** (`v0.2.1` line). DB defaults to the XDG data dir, not
  cwd-relative — fixes "CLI not using my data" from another directory.
  `HOMEWATCH_HOME` sets a self-contained project root; `HOMEWATCH_DB` overrides.
  `homewatch info` prints what's in effect.
- **endoflife.date source.** Authoritative Apple-OS dates
  (ios/ipados/macos/tvos/watchos/visionos). Gap-fills undated versions and adds
  major-release dates.
- **Date precision.** HomePod dates derived from tvOS (`≈ tracks tvOS`);
  everything still undated shows `≤discovered_at`. Display-only; stored dates
  stay honest.
- **Ergonomics.** `-V/--version`, `-h` at all levels, `products` listing +
  completion + unknown-product hints, `releases` defaulting to last 3 months /
  stable (`--months N`, `--all`), `--urls` and md/html links for click-through.

## Verified (live)

- `refresh` pulls HA core (atom) and endoflife (138 dated releases) into the
  local DB; idempotent re-pull; WAL checkpoint on shutdown.
- HomePod 13–18 versions placed on the timeline via tvOS dates (`≈…`).
- Location-independence: same DB path from repo dir and `/tmp`.
- 94 tests green.

## Open / suggestions

- **GitHub release notes**: `show` scrapes the release *page* and reduces to
  text. The GitHub Releases API would give clean markdown bodies — tidier
  follow-up.
- **`latest` tie-break**: same-day Apple patches across cycles can pick the
  wrong "latest" by id. Prefer higher version on a date tie.
- **HomePod security HTML** is now JS-rendered; if Apple restores a static
  table or ships a feed, add it and drop reliance on tvOS derivation for dates.
- **HA / HomePod LAN probes** are unit-covered only (need hardware / same-L2 to
  exercise live). The `POST /probe/ingest` LAN-agent path is wired but unused.
- **v2 stretch**: `page_snapshots` urlwatch-style diffing (spec §3.7); notify
  on `watch --until-new` (currently prints + exits).
