# Session 2026-06-11 — device inventory, status, packaging

## Shipped

- **Device inventory (`v0.4.0`–`0.4.5`).** `devices` is a first-class noun:
  probes auto-enroll devices (MAC/mDNS identifiers, SSID/IP/subnet, detected
  name) and write `enrolled`/`retired` events to the timeline. `devices
  list/show/history/retire/rename`, top-level `enroll`, and **`status`** (per
  device, running vs latest — "am I behind?"). `devices rename` sets a display
  name kept separate from the detected one; `devices list PATTERN` is a
  smartcase/regex search across all fields.
- **HomePod detection fixed (`0.4.1`), verified live.** pyatv often leaves
  `model` Unknown; now classify on the AirPlay TXT (`AudioAccessory*`/`osvers`)
  + device name, capturing name/version/IP/MAC. `probe homepods --raw [--host
  IP]` to debug / unicast. (Bedroom HomePod 26.5 @ 192.168.42.20.)
- **Apple URL fix (`0.3.3`/`0.3.10`).** Parser absolutizes relative hrefs;
  migration 003 backfills already-stored ones (gap-fill kept the relative).
- **Time & filtering.** `--since` parses systemd-style relative spans;
  `releases` defaults to last 3 months, **oldest-first** (time flows down),
  `--channel all`, `-r`. HomePod ordering via tvOS-derived effective date.
- **admin tree (`0.4.4`).** `admin migrate status|backup`, `admin info` — off
  the top level, room for housekeeping.
- **Packaging (`0.4.6`).** PyPI metadata + `[probe]`/`[zeroconf]`/`[all]`
  extras; wheel bundles migrations + templates. Not published — README has
  run-from-GitHub (uvx/pip/uv tool); default install is the lean version
  tracker, LAN probing is opt-in.
- **Config/data-root.** XDG default + `HOMEWATCH_HOME`; config file `env` (XDG)
  / `.env` (cwd); `info` distinguishes `read` vs `checked, absent`.
